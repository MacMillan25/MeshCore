# Ветка lr2021 — DarkTec на LR2021

Тестовая ветка: та же плата DarkTec (nRF52840, SSD1306, INA3221, кнопка,
буззер, GPS), но вместо E22 — модуль NiceRF **LoRa2021F33-2G4** на проводках.

## Распиновка (20.10.2026)

| Сигнал | nRF | Arduino-пин |
|---|---|---|
| SCK | P1.13 | 13 |
| NSS | P1.11 | 12 |
| BUSY | P1.15 | 14 |
| MOSI | P0.02 | 15 |
| MISO | P0.09 | 10 |
| RESET | P0.29 | 16 |
| IRQ | P0.10 | 11 |
| Питание модуля | P0.13 | 21 |

- `P0.17` (бывший пин 6 E22) никуда не идёт, держится высоким.
- `CE` модуля не подключать: это включение внутреннего LDO, внутри подтянут
  вверх; низкий уровень — сон (тогда все ноги MCU тоже в низкий).
- Питание модуля 3.0–5.5 В; на плате это батарейный/переключаемый рейл.

## RF-тракт модуля

Модуль сам ничего не коммутирует: усилители, LNA и ключ 5-вольтового питания
висят на DIO чипа. Роли сняты с блок-схемы модуля:

| DIO | Что делает |
|---|---|
| DIO7 | `Power_EN` — PMOS, питание усилителя 5 В |
| DIO6 | `TXEN` усилителя sub-GHz + ключ антенны |
| DIO8 | `TXEN` усилителя 2.4 ГГц |
| DIO5 | `LNA` 2.4 ГГц (по даташиту нормально держать высоким) |

Таблица — в `variants/darktec/target.cpp` (`rf_table_main`): передача —
DIO6 и DIO7 высокие, приём и standby — все низкие. Проверено на живом эфире.

Антенные выходы: `ANT` (пин 9) — sub-GHz, `ANT-2G4` (пин 10) — 2.4 ГГц.
Антенна — только в sub-GHz; 2.4 ГГц модулю не нужен.

## Почему обёртка читает пакет сама

`DarktecLR2021Wrapper` забирает пакет из FIFO в тот же момент, когда опрос
увидел `RX_DONE`, и отдаёт ядру готовые байты. Штатный путь не работал: пока
пакет ждал чтения, кто-то сбрасывал `HEADER_VALID`, и `readData()` браковал
целый пакет как «заголовок битый» (симптом: `irq=0x40110` без бита `0x40`,
`err` растёт, пакетов нет).

Заодно:
- **CAD выключен** (`setCADEnabled` игнорируется): `scanChannel()` стирает IRQ
  и перезапускает приём.
- `isReceivingPacket()` свой, без сброса флагов.

## CLI

```
lr2021                 # состояние: частота, полоса, SF/CR, RF-маска, статус, счётчики
lr2021 scan 10         # 10 с слушать и посчитать преамбулы/пакеты/ошибки CRC
lr2021 listen 15       # приём в обход меша, с печатью байтов
lr2021 tx 5            # передать 5 сырых пакетов, посчитать TX_DONE
lr2021 spi             # 200 чтений версии чипа — проверка шины
lr2021 boost 0|1       # усиление приёмника
lr2021 rf N            # вариант таблицы RF-ключа (1 штатный ... 5)
lr2021 rx N            # маска DIO5..DIO8 в приёме (бит0=DIO5 ... бит3=DIO8)
lr2021 dio N 0|1       # выставить ногу DIO вручную
lr2021 irq N           # перевести ногу N в прерывание
lr2021 none            # отпустить DIO5..DIO8 в Hi-Z
```

## Сборка и прошивка

```
pio run -e Darktec_companion_radio_usb -t create_uf2
```

UF2 — в `out/uf2/lr2021-<env>.uf2`.
